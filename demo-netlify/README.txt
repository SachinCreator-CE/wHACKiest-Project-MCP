SentinelAI console: static demo
===============================

This folder is a complete static site. There is no server, no build step and no AWS access.

To publish: open Netlify > Deploys and drag this folder (or the matching .zip) onto the drop area.
index.html is at the root of the folder.

What it is: the real console files, answered from responses recorded from SentinelAI's offline
fallback. Approvals and reports are simulated in the browser only; reload to reset.

Source: https://github.com/SachinCreator-CE/wHACKiest-Project-MCP
